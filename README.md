# 三向投影 · 最少体素重建（voxels）

离线单页应用：编辑三张二值正交投影（XY / XZ / YZ，各维 2～3），求占用体素数最少的立体模型。

## 问题定义

- 体素坐标 `(x, y, z)`，范围 `0..nx-1 / 0..ny-1 / 0..nz-1`，每维 2 或 3，z 轴向上。
- 投影约定：`xy[y][x]`（沿 z 轴）、`xz[z][x]`（沿 y 轴）、`yz[z][y]`（沿 x 轴）。
- 体素可占用（候选）的必要条件：三个对应投影格全为 1。
- 可行解：每个为 1 的投影格至少被一个选中体素覆盖（候选体素的投影必为 1，故可行解的三向投影恰好等于输入）。
- 目标：体素数最少；并列时取「按 (x,y,z) 排序后的体素列表」字典序最小者。
- 无解：报告首个没有任何候选体素支撑的投影格（扫描顺序 XY → XZ → YZ，平面内行主序）。

> 注意：填满所有候选体素一般不是用料最少的方案（如 2×2×2 全 1 投影：候选 8 个，最优 4 个）。

## 求解方法

精确分支限界（最约束投影格优先分支 + 「每体素至多新覆盖 3 格」下界）先求最少体素数 k，
再按 (x,y,z) 升序贪心决定每个候选体素去留（以同一求解器作可行性预言机），得到字典序最小解。
规模 ≤ 27 体素，瞬时完成。

## 页面

- 三张投影网格：点击切换 0/1，按住拖动连续绘制；无解时红框标出首个无支撑格。
- 等轴（isometric）SVG 视图：候选体素半透明、最优解实心，实时联动。
- 任何编辑（投影格、维度）都会清除旧结论，需重新点击「重建最少体素模型」。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # Vitest：2×2×2 穷举对拍 + 轴置换一致性
npm run check    # svelte-check 类型检查
npm run build    # 产出 dist/ 静态文件
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

`docker-compose.yml` 中的 `voxels` 服务：多阶段构建（node 构建 → nginx 托管），完全离线。

## 测试说明（Vitest）

- **穷举对拍**：2×2×2 的全部 2^12 = 4096 组投影，与暴力枚举全部 2^8 = 256 个体素子集的结果逐一比较
  （可解性、最少体素数、字典序最小体素列表、解的三向投影与输入一致）。
- **轴置换一致性**：6 种轴置换下最少体素数不变；置换后问题的解、以及原解坐标置换后的三向投影，
  都与置换后的投影一致（另附随机 2～3 维投影与置换机器自洽性检验）。
