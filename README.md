# 三向投影体素重建（voxels）

Svelte + TypeScript + SVG 的离线单页应用：编辑 XY / XZ / YZ 三张二值正交投影（各轴尺寸 2～3），
求**占用体素数最少**的立体模型；并列时取按 `(x,y,z)` 排序后字典序最小的体素列表；
无解时指出首个没有任何候选体素支撑的投影格（按 XY → XZ → YZ 面、面内第二轴升序、同行第一轴升序判定）。

规则：

- 体素 `(x,y,z)` 可占用的必要条件：`XY[x][y]`、`XZ[x][z]`、`YZ[y][z]` 三格都为 1；
- 每个为 1 的投影格必须至少被一个选中体素覆盖；
- 随意填满所有允许体素不等于用料最少 —— 本页用带下界剪枝的搜索求最小集合，并逐位构造字典序最小解。

页面联动：左侧三向掩码（点击切换 0/1）、右侧等轴图与结论；**任何编辑都会清除旧结论**，点击「重建」重新求解。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # Vitest：2×2×2 全投影穷举对拍 + 轴置换一致性
npm run build    # 产出 dist/
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

## 测试说明（src/lib/solver.test.ts）

- **穷举对拍**：2×2×2 下全部 4096 组投影，与“枚举全部 256 个体素子集”的暴力参考实现逐一比对
  最少体素数与字典序最小列表；无解时校验被报告格确实无候选支撑、且判定顺序在前的为 1 格均有支撑。
- **轴置换**：随机投影在全部 6 种轴置换下，最少体素数不变、解的三向投影与（置换后的）输入一致，
  且原解置换坐标后仍是合法解。
